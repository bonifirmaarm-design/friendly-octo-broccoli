# Игра

Three.js, чистые ES-модули, без сборки. Библиотека лежит в `vendor/`, поэтому
интернет не нужен вообще.

## Запуск

Сервер поднимается **из корня репозитория**, а не из `game/` — игра тянет
модели из `build/`.

```bash
python3 tools/stl_to_glb.py --scales   # NPC и предметы  -> build/glb
python3 tools/build_arena.py           # арена           -> build/arena
python3 tools/populate.py              # зрители, расстановка
python3 tools/autorig.py               # скелеты         -> build/rigged
python3 tools/animate.py               # анимации        -> build/animated

python3 -m http.server 8000
```

Открыть `http://localhost:8000/game/`.

Любой статический сервер подойдёт (`npx serve`, `php -S`), важно только, чтобы
корнем был репозиторий: пути к моделям идут как `../build/...`.

## Что где

```
index.html        меню, экран управления, выбор бойца, HUD
src/main.js       автомат состояний: меню -> выбор -> выход -> бой -> награждение
src/combat.js     раунды, урон, блоки, переводы
src/ai.js         бот: по дистанции, потом по характеру; в партере — своя ветка
src/fighter.js    обёртка над GLB: клипы, стамина, тайминги ударов
src/camera.js     три камеры: трансляция, ближняя, угловая
src/scene.js      свет, вспышки фотоаппаратов, кровь
src/controls.js   раскладка (одна на всё: и меню, и игра читают её отсюда)
src/roster.js     ростер и веса стиля для бота
test/             проверки боевой логики без браузера
assets/portraits  портреты бойцов для меню
vendor/           three.js и GLTFLoader
```

## Проверка

```bash
node test/ground.test.mjs      # 17 проверок партера, судьи и гонга
```

Тест гоняет `combat.js` без браузера: боец подменяется заглушкой, потому что
боевая логика трогает его через очень маленькую поверхность — `play`, `has`,
`clipLength`, позиция. Это секунды вместо минут, которые уходят на прогон
через софтверный рендер.

## Как устроен удар

Удар засчитывается **не в момент нажатия, а в середине анимации**. Этот зазор и
есть вся игра: джеб доходит раньше хука, а блок можно поставить уже после того,
как соперник начал замах. Окна прописаны в `STRIKES` в `src/fighter.js` — там же
урон, цена по стамине и дальность.

Бот выбирает **сначала по дистанции, потом по характеру**: борец, который
проходит в ноги с четырёх метров, выглядит сломанным, поэтому веса стиля решают
только между приёмами, уместными с той дистанции, где он стоит.
